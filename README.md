🎉 موقع السحب العشوائي

أداة بسيطة وسهلة لاختيار الفائزين في المسابقات والسحوبات العشوائية.

✨ مميزات الموقع

- اختيار فائز عشوائي من قائمة أسماء.
- مناسب للمسابقات وصنّاع المحتوى.
- مفيد للمدرسين في اختيار الطلاب عشوائيًا.
- واجهة سهلة الاستخدام.
- يساعد على تنظيم عمليات الاختيار العشوائي.

🚀 طريقة الاستخدام

1. افتح الموقع.
2. أدخل الأسماء أو البيانات المطلوبة.
3. ابدأ عملية السحب.
4. اعرض النتيجة لمعرفة الفائز.

🛠️ التقنيات المستخدمة

- HTML
- CSS
- JavaScript (إذا كان مستخدمًا في الموقع).

📌 ملاحظة

هذا المشروع أداة للاختيار العشوائي، ويُفضّل استخدامه في المسابقات الترفيهية والتعليمية غير الحساسة.
